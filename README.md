# 📚 Simple Learning Management System (LMS)

A web-based **Learning Management System** with:

- 👨‍🏫 Mentoring
- 👥 Group / Class creation
- 📹 Video meetings
- 📝 Activity submission
- 🏆 Certificate generation
- 👤 User roles (Admin / Mentor / Student)

Built using:

- PHP  
- MySQL  
- HTML / Tailwind CSS  
- JavaScript
